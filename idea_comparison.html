③

① 三維無障礙／全天候微導航

CSDI 3D 行人路線 API（travelMode 1–5）現成可用，社會價值最高、比賽最契合；但係要處理 Z 軸高程、室內外無縫，技術中等。
  • 受眾：輪椅／BB 車／長者／搵冷氣通道市民
  • 變現：商場餐飲導流分潤 + 社創基金
② 首推

② 公屋／簡約公屋 AI 配對

技術最低、數據最 ready（房屋局 / 房委會 / 教育局 / 社署 JSON、CSV 現成，我哋 CKAN API 已證實拉得到）；變現最直接（裝修／傢俬／寬頻導流）。
  • 受眾：公屋申請家庭、社工、NGO
  • 變現：本地商戶精準導流佣金
③

③ 物流署拍賣／招標 AI 雷達

333 個 CSV 需爬蟲清洗，但 LLM 標準化 + 歷史成交價向量匹配係清晰護城河；Freemium 訂閱變現直接。
  • 受眾：二手貿易商、競投政府合約嘅中小企
  • 變現：免費瀏覽 → 付費 AI 估價／推送
④

④ B2B 職安健／法例 DD 引擎

變現確定性最高（B2B SaaS 按次／年訂），但 entity resolution + 法例版本 RAG diff 技術中高，前期做功多。
  • 受眾：業主立案法團、物管、合規、律所
  • 變現：Pay-per-report / 年訂
⑤

⑤ 北都／空置用地 GeoAI 沙盒

CSDI 比賽契合度最高（呼應官方 GeoFun 趨勢）、護城河最強；但 3D 空間分析／視域／飛行走廊演算法技術最高，5 週內要出原型壓力大。
  • 受眾：規劃師、環保 NGO、低空經濟初創、工程顧問
  • 變現：獎金 + B2B 顧問軟件
⑥

⑥ 時空文化／影視朝聖／3D 泊車

題材有趣、數據齊（歷史地圖、舊照片、泊車感應器 API）；但泊車 App 偏紅海，文化類商業化較慢，綜合最適合做興趣 side project。
  • 受眾：深度遊旅客、文化愛好者、考車學神／覓位車主
  • 變現：旅遊分銷 + 車主增值服務

🎯 我的起步建議：按你嘅目標二選一

目標 A —— 最快出到嘢、最快見錢（推薦先打呢條）：揀 ② 公屋／簡約公屋 AI 配對。 技術難度最低、數據最 ready、變現路徑最直接，最啱「未有 idea、想先做出個嘢」。我哋可以即刻用 CKAN API 拉房屋局／房委會／教育局／社署數據，2 週內出到一個可用原型。

目標 B —— 想搏 CSDI Awards 2026（12-05 截止）、建立技術護城河：揀 ① 三維微導航 或 ⑤ 北都 GeoAI 沙盒。 兩者比賽契合度滿分；① 技術中等較易喺 5 週內成嘢，⑤ 技術最高但一旦做成最驚艷。建議申請 Geospatial Lab 比賽專用帳戶先測 3D 路線 API。

💡 折中玩法：先用 ② 練手搭數據管線（Stage 1），再用同一套 JSON/地圖技術去撐 ① 嘅前端——兩條線共用地基，唔會白做。

📍 如果你揀咗 ②，下一步我可以直接幫你做嘅（Stage 1）

第 1 步
寫 Python 腳本經 CKAN API 拉：簡約公屋 API、房委會公屋單位、學校位置、課後託管名單。
