①平台定位與搜尋面板架構

CSDI（Common Spatial Data Infrastructure，空間數據共享平台）係香港政府嘅官方空間數據目錄，由地政總署營運， 同 DATA.GOV.HK（CKAN）互補：CSDI 專注有空間屬性嘅數據集，元數據符合 ISO 19115 標準。

🔍 架構結論：CSDI Portal 係 Esri Geoportal Server 2 架構（Elasticsearch 後端）。前端 #searchPanel 只係 hash 路由； 真正嘅搜尋引擎喺 GET https://portal.csdi.gov.hk/geoportal/rest/metadata/search?f=json—— 同項目現有「通用抓取器」同一套理念：唔使開瀏覽器，直接打 API 就可以做全站數據集偵察。

🏗️ 座級定位升級方案（取代 OSM 匹配）

接入點：build_app.py 座級定位模組｜現況：OSM 匹配覆蓋率不保證、「第N座」跳過
做法：每邨以 mtr_candidates 同款 bbox（約 500m）查 BuildingBlockType='Tower' AND BuildingNameTC IS NOT NULL → 座名正規化（全形／半形、去空格）後同管線座名匹配 → polygon centroid（returnGeometry=true 取 rings 平均）即座級座標。
🎯 三大着數：① 官方數據（地政總署維護，覆蓋全港 342 萬… 34.2 萬幢，唔靠 OSM 眾包）； ② 連「第N座」都有名（華景山莊第二十座實測在列），OSM 跳過嘅座可以補返； ③ 免費送樓高／層數（Storeys/TopHeight）——卡片可以加「呢座幾多層」剖面資訊。注意同名 Tower/Podium 要 filter Tower＋最大面積去重；座名匹配保留現有正規化邏輯。
