# 屋邨智配・3D 無障礙生活圈

**全類型房屋（公屋／簡約公屋／居屋／私人屋苑／鄉村）智能配對與三維無障礙出行平台** —— 空間數據共享平台大獎 2026（CSDI Awards 2026）公開組參賽原型。

> 兩步式解決兩個城市痛點：
> **① 智能配對** — 由單位級政府數據即時篩選合適屋邨，輸出「生活圈評分卡」（港鐵／小學／託管可達性）；
> **② 3D 實測出行** — 一鍵調用地政總署三維行人路線 API，以無障礙、避雨、行樓梯等模式規劃屋邨 → 港鐵站實測步行路線，附繁中逐向導航與垂直高差。

## 快速開始

零第三方依賴（純 Python stdlib + 前端 Leaflet CDN）。

```bash
# 1. （可選，約 2–5 分鐘）重跑數據管線：下載 18 區公屋單位 + 學校 + 託管點 + 評分
python pipeline_stage1.py    # 簡約公屋 28,951 單位 + 公共屋邨名單
python stage2_full.py        # 18 區公屋聚合 + 小學 + 託管 → 生活圈評分

# 2. 注入數據產出單檔原型（每次數據更新後重跑）
python build_app.py          # → index.html

# 3. 起本地服務（3D 路線 API 需要 http(s) 環境，file:// 會被瀏覽器擋）
python -m http.server 8642
# 打開 http://127.0.0.1:8642/（index.html）
```

**環境需求**：Python 3.8+（管線）；現代瀏覽器（原型）；網絡可連 `mapapi.hkmapservice.gov.hk`。

## 數據管線

### Stage 1 — `pipeline_stage1.py`
- 下載房屋局「簡約公屋」單位級 JSON（28,951 條）→ `lph_units.csv`、項目級聚合 → `lph_projects_summary.csv`
- 下載房委會 ES Locator 公共屋邨名單（245 個邨）→ `prh_estates.csv`
- 純 stdlib（`urllib` / `csv` / `json`），無需虛擬環境

### Stage 2 — `stage2_full.py`
1. **18 區房委會公屋單位**：`ha_prhs_{a..t}_en.json` 逐區下載，大檔用 `stream_records()` 流式解析（regex 切分避免 MemoryError），按屋邨聚合：升降機單位統計、平均面積、樓宇數、樓層範圍
2. **教育局學校位置** `SCH_LOC_EDB.json`：過濾小學（3,400+ 間學校 → 約 600 間小學）
3. **社署在校課後託管**：CSDI WFS `typename=csdi:SWDSBAEPS` → GeoJSON 服務點
4. **港鐵場地**：`mtr_venue_polygon.json`（98 個場地 bbox 中心）
5. **CSDI 新數據集**（Part 5）：社署長者日間護理單位（3）＋民政署社區會堂（115，合併 19 個避暑中心標記＋119 條無障礙設施記錄）；通用抓取器 file-api → FeatureServer → static fallback，動態鍵名解析兼容 2026-10 欄位改名
6. 合併 LPH(10) + PRH(~248)，每個屋邨計算最近港鐵／小學／託管／長者中心／會堂（haversine）＋ 800m 密度 + 七維生活圈評分（第 7 維有蓋步行由 `covered_network.attach()` 掛上）→ `all_estates_enriched.json`（258 邨全數有座標：3 個 2026/27 新邨以人工核定座標補全）

### Build — `build_app.py`
- 讀取 `all_estates_enriched.json`，為每個有座標屋邨**計算最近 3 個港鐵站候選**（`mtr_candidates`，雙錨點：邊界最近點＋站體中心）
- **座級定位**：以 OSM Overpass 查詢屋邨 400m 內 named buildings，與管線座名（耀康樓等專名）精確匹配，為座塊補座標；快取於 `osm_block_coords.json`（「第N座」通用名跳過避免誤配）
- 注入 `estate_matcher_template.html` 的 `__DATA__` 佔位符 → `index.html`
- 內建安全檢查：payload 不得含 `__DATA__` 或 `</script`

1. **平滑衰減取代硬性分段**——消除「斷崖效應」：`S(d) = 100 × exp(-ln2/hl × max(0, d-d0))`，d0 為滿分半徑、hl 為半衰距離；無數據返中位數 50 分。分佈呈平滑曲線，加入五維（含急症醫院）後**全港冇屋邨再並列滿分**，排序鑑別度恢復。
2. **距離 ＋ 800 米選擇密度**——小學分 ＝ 60% 最近距離 ＋ 25% 800m 小學密度（5 間滿分）＋ 15% 800m 幼稚園密度（3 間滿分）；託管分 ＝ 80% 距離 ＋ 20% 密度（3 間滿分）。反映「步程內有幾多間可以揀」嘅真實生活圈資源差異。

## 3D 路線 API 使用說明

**端點**：`https://mapapi.hkmapservice.gov.hk/PedRoute/NAServer/route/solve`（ArcGIS NAServer REST 慣例，注意係 `/route/solve` 唔係 `/route`）

**關鍵參數**：

| 參數 | 值 | 說明 |
|------|-----|------|
| `stops` | `lng,lat;lng,lat` | 順序係 **經度,緯度**（WGS84, EPSG:4326） |
| `returnZ` | `true` | 返回每個路徑點 (x, y, z, m)，z 用於高差統計 |
| `outSR` | `4326` | 輸出 WGS84，免除前端 HK1980 轉換 |
| `travelMode` | 1–5 | 見下表 |
| `directionsLanguage` | `zh-HK` | 繁體中文逐向導航 |
| `directionsStyleName` | `NA Campus` | 步行導航樣式 |

**出行模式**（`retrieveTravelModes` 實測確認）：

| travelMode | 模式 | 場景 |
|---|------|------|
| 1 | 最短路徑 | 基準 |
| 2 | 無障礙路徑 | 輪椅／嬰兒車：避梯級、優先升降機 |
| 3 | 推薦路徑 | API 預設 |
| 4 | 行樓梯健身 | 運動場景 |
| 5 | 非付費區優先 | 落雨免擔遮／全程有蓋有冷氣 |

**8 個目的地類型與錨點策略**（全部經同一 `/route/solve` 端點實測）：

| 目的地 | 錨點來源 | 策略 |
|--------|----------|------|
| 🚇 港鐵站 | `mtr_venue_polygon` 多邊形 | 最近 3 站 × 雙錨點（邊界最近點→站體中心）逐個試 |
| 🏫 小學 | EDB 學校座標 | 最近 3 間逐個試 |
| 🎒 課後託管 | 社署 SBA 服務點 | 最近 1 點 |
| 👵 長者日間護理 | 社署 DCUDECC | 最近 1 點 |
| 🌡️ 社區會堂／避暑中心 | 民政署 CHCC | 最近 1 點 |
| 👶 幼稚園 | EDB 幼稚園（去重） | 800m 內**全部**列清單，用戶逐間揀 |
| 🎠 共融遊樂場 | LCSD pefac（DMS→十進制） | 最近 1 點 |
| 🏥 急症醫院 | OSM `emergency=yes` | 5km 內**全部**列清單（上限 12），用戶逐間揀 |

**多段路線鏈（3 停靠點）**：`stops=屋邨;中轉設施;港鐵站` 一次請求——「育兒返工鏈」（屋邨→託管→港鐵）與「護老返工鏈」（屋邨→長者中心→港鐵）；回應 `directions` 按段分組（每段 `features[].attributes.text` 為繁中步驟），前端以編號地圖釘（1/2/3）標示並合併分段導航；站×錨點組合同樣逐個 fallback。

**實例**：
```
# 單段（屋邨 → 港鐵，無障礙模式）
/route/solve?stops=114.128,22.366;114.132,22.368&travelMode=2&returnZ=true&outSR=4326&directionsLanguage=zh-HK
# 多段（屋邨 → 託管 → 港鐵）
/route/solve?stops=114.128,22.366;114.129,22.367;114.132,22.368&travelMode=2&returnZ=true&outSR=4326
```

**錯誤對照表**（實測整理）：

| 錯誤 | 意思 | 應對 |
|------|------|------|
| `400 / Unable to complete operation / No route from location ...` | 兩點之間**冇可行行人路**（隔住海、快速公路、封閉範圍），唔係系統故障 | 換候選站；離島屋邨（長洲、坪洲、梅窩、赤柱等）本質上冇路去任何港鐵站 |
| `GET /route` 只返服務資訊 | 打錯端點（少了 `/solve`） | 用 `/route/solve` |
| 前端 fetch 失敗 | 用 `file://` 開啟（CORS origin null）或網絡不通 | 用 `python -m http.server` 等 http(s) 環境開啟 |

## 已知限制與疑難排解

1. **必須以 http(s) 開啟**：3D 路線 API 由 `file://` 調用會被瀏覽器 CORS 擋。請 `python -m http.server` 後經 `http://127.0.0.1:8642/` 開啟（或直接用 GitHub Pages 線上版）。
2. **3 個新屋邨座標為人工核定**：古雋邨（古洞北）、華富北邨（薄扶林）、曉茵邨（秀茂坪）房委會單位檔無座標，已以核定座標補全（`coords_note` 欄位註明來源與說明），全港 258 邨 100% 可上圖、可規劃路線；日後可用 CSDI 地址搜尋服務覆核。
3. **6 個離島／無鐵路覆蓋屋邨無法規劃港鐵路線**：長貴邨（長洲）、金坪邨（坪洲）、銀灣邨（梅窩）、馬坑邨（赤柱）、龍田邨、雅寧苑 —— **地理事實，非 bug**。已加 **⛴️ 渡輪碼頭錨點**（運輸署 74 個碼頭）：長貴→長洲碼頭 678m、金坪→坪洲碼頭 289m、銀灣→梅窩碼頭群 549m，可規劃 3D 路線去碼頭。
3.5. **座級定位三層 fallback**：CSDI bbox → LandsD → OSM，**95.4%** 有官方座標。未匹配 79 座主要係舊邨座名變體。座級路線起點為建築物中心，非單位門口。
3.6. **長者維度已升級**：由僅 3 個 DCUDECC 點擴展至 345 點，鑑別度恢復；幼兒中心 326 點補齊 0–6 歲缺口。
3.8. **房屋類型擴張（v4.0）**：居屋／私人／村屋冇公開單位級數據（私隱）→ 單位數／升降機／座別等欄位**如實 N/A**（評分自動重歸一化，唔硬補估算）。私人屋苑人口／收入為 **2021 普查時點**（UI 已聲明）；鄉村為**村級**錨點（分界多邊形中心，非逐屋）；私人屋苑 district 由最近官方屋邨推斷（顯示用途）。
3.9. **卡片規模**：1,422 錨點（248 公屋＋10 簡屋＋240 居屋＋230 私人＋694 村），index.html 約 8.4 MB，首次載入需數秒。
3.10. **有蓋步行維度係「密度」唔係「路徑」**：`covered` 反映 500m 內行人天橋／隧道／通道上蓋嘅**資源密度**（路政署 2,116 個構築物、320.4 km），**唔證明**點對點全程有蓋。曾試「往港鐵直線走廊有蓋率」，因直線穿樓宇、非真實步行線（781 邨中位僅 15.4%）而**棄用**；真正連通分析要行 465,892 段 3D 路網做圖論，屬賽後擴展。另：路政署只收**公共**構築物，私人屋苑內部有蓋通道唔在內。
3.11. **座別覆蓋率**（`audit_blocks.py` 全量審計：0 錯誤／2 提示）：公屋 248/248、簡屋 10/10、居屋 237/240、私人 **204/230**（26 個普查分界缺失或地政總署無同名樓宇，例：YOHO Midtown／花園城／家維邨）。居屋 3 個冇座名（源數據只有「A」或空白）；雲叠花園／澤豐花園源數據只給「第一座至第N座」範圍字串、拆唔到 → **唔顯示座別按鈕**（唔會顯示一行假座）。私人屋苑座名來自普查分界內嘅地政總署 Tower，已剔除非住宅（學校／商場／變電站）同佔位名。
3.7. **EMSD 升降機覆核**：機電署 74,550 部中 14,029 條公屋相關，地址解析後匹配 229/258 邨（88.8%）、1,234/1,713 座（72.0%）。EMSD 數含商場／停車場等附屬設施，通常高於「有𨋢單位數」；29 邨無 EMSD 記錄多為新邨／簡約公屋。
4. **距離為直線（haversine）近似**：評分卡距離非實測步行距離；實測路線以 3D API 為準。**錨點設計**：港鐵錨點取「場地多邊形邊界最近點」（點到線段投影）＋「站體中心」**雙錨點 fallback**，前端逐錨點嘗試——bbox 中心可能跌入站體範圍令網絡 snap 唔到（實例：天耀一邨→天水圍站直線 73m，邊界點實測 193m ✅，bbox 中心 ✗），邊界點亦可能面向路軌（葵涌邨→大窩口站直線 150m，中心實測 696m ✅，邊界點 ✗）。
5. **API 紀錄上限**：CSDI 服務單次查詢上限 5,000 條紀錄；管線以 18 區分檔下載、前端按場地逐個調用，已避開。
6. **舊座標系歷史數據**：個別數據集含 HK1980（EPSG:2326）EASTING/NORTHING 欄位，已於管線層處理；3D API 統一 `outSR=4326` 直出 WGS84。
7. **數據時效**：官方偶有欄位改名（2026-10 例子）；重跑 `stage2_full.py` 即可重新對齊。
8. **幼稚園／醫院／遊樂場範圍**：幼稚園來自 EDB 全港名單（1,224 間，每邨列 800m 內全部，平均 15.4 間）；急症醫院為 OSM `emergency=yes` 23 間（每邨列 5km 內全部，平均 2.8 間）；共融遊樂場只有 LCSD 44 個指定場地，故 `playgrounds_800m` 多為 0–1，屬正常。
9. **天氣聯動依賴 HKO API**：前端 `fetchHkoWeather()` 有 try/catch，離線或 API 異常時天氣 pill 顯示「—」、banner 隱藏，完全不影響篩選與 3D 路線；🧪 模擬按鈕可離線演示避雨路線聯動。
